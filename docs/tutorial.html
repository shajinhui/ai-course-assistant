02 / INSTALLATION

安装与启用

1. 准备浏览器扩展

  1. 安装 Tampermonkey（篡改猴）

    打开 Tampermonkey 官方网站，选择你的浏览器，前往对应扩展商店安装。安装完成后，可将扩展固定到浏览器工具栏，便于打开管理面板。

  2. 确认用户脚本执行权限

    Chrome 138 及以上版本，可进入扩展管理页，打开 Tampermonkey 的详情，启用「允许用户脚本 / Allow User Scripts」。较旧版本或其他 Chromium 浏览器若提示开发者模式，请按 Tampermonkey 给出的官方步骤设置。

    扩展管理→Tampermonkey 详情→允许用户脚本

    Chrome 的权限入口自 138 版起调整，见 Chrome 官方说明；其他浏览器的具体步骤见 Tampermonkey 权限说明。

浏览器扩展管理地址复制后粘贴到地址栏
Chromechrome://extensions/
Edgeedge://extensions/

2. 安装小肥鱼AI

  1. 获取单文件安装包

    进入 项目最新 Release，找到附件 ai-course-assistant.user.js。也可以使用下面的直接下载入口。

    下载最新 .user.js ↗

  2. 在 Tampermonkey 中确认安装

    浏览器出现脚本安装页面时，确认名称为「小肥鱼AI」，点击安装。回到油猴管理面板，确认脚本处于启用状态。

  3. 进入网课网站并刷新

    打开匹配的智慧树、超星等网课页面。右下角的星形悬浮按钮，鼠标悬停或键盘聚焦后会显示「小肥鱼AI」，点击即可打开面板。平台首页可能只有通用功能，课程操作需要进入具体页面。

浏览器只下载了文件，没有弹出安装页面怎么办？

可以在 Tampermonkey 管理面板的「实用工具」中尝试文件导入。如果你的版本未提供相应入口，使用下面的编辑器方式：

  1. 用文本编辑器打开下载的 .user.js，复制全部内容。
  2. 打开 Tampermonkey，选择「添加新脚本」。
  3. 清空默认模板，粘贴完整脚本，包含最上方的 // ==UserScript== 元数据头。
  4. 按 Ctrl + S 保存；macOS 编辑器可使用 ⌘ + S。
  5. 确认脚本启用，再刷新网课页面。

编辑器粘贴安装方式参见 Tampermonkey 官方安装说明。

04 / CONNECT YOUR MODEL

配置自己的 AI 接口

先向你的 API 服务商取得三项信息：接口地址、API Key、模型 ID。脚本使用兼容 Chat Completions 的文本接口，服务需要能返回文本回复。

设置项填写方法示例 / 默认值
API 地址填写完整的 HTTP(S) 接口基础地址，或完整的 /chat/completions 地址。应使用服务商提供的 API 地址。https://api.example.com/v1
API Key填写该服务商控制台创建的密钥。脚本会自动添加 Bearer 鉴权前缀，输入框只需密钥本身。密钥使用密码框显示；无需鉴权的本地服务可留空。
模型名称填写此接口实际支持的准确模型 ID，拼写与大小写按服务商文档填写。your-model-id 是占位示例，需替换。
请求超时（秒）允许范围 5～300 秒。响应慢时可适当增加。默认 60
聊天系统提示词控制聊天回答的语言、语气与讲解方式。自动搜题使用脚本自己的结构化答题提示词。默认要求用中文清晰回答。

上面的域名和模型 ID 都是示例。接口使用量与计费规则以你的服务商为准。

  1. 点击「AI 聊天」

    在设置区域逐项填写地址、Key 和模型名称。每项填好后，点击输入框外的位置让更改保存。

  2. 点击「测试连接」

    脚本会发送一条简短请求，请模型回复 OK。出现「连接成功：…」说明这次请求拿到了文本回复；测试不会加入聊天上下文。

  3. 发送一个简单问题

    例如「用一句话解释什么是光合作用」。看到回复后，再使用在线搜题或课程页面的功能。

API 地址会怎样拼接？

仅在本页计算 · 不发送请求 · 不保存输入

选择示例，或输入地址，查看脚本最终请求的路径。

最终请求地址https://api.example.com/v1/chat/completions

本地服务的端口、模型 ID 和鉴权方式，应按你实际启动的服务填写。

输入实际请求路径
https://api.example.com/v1/chat/completions
https://api.example.com/v1/v1/chat/completions
https://api.example.com/api/v1/api/v1/chat/completions
完整 …/chat/completions使用这个完整地址。

遇到非标准路径时脚本会保留你填写的路径，再追加 /chat/completions；只有根地址会补上 /v1。如果服务商要求特殊路径，直接填写其完整 Chat Completions 地址。URL 中包含用户名、密码或 #片段 时，脚本会提示地址无效。

05 / CHAT

用 AI 聊天学习

  1. 在「AI 聊天」中输入问题

    可以要求解释概念、梳理课程重点、分析一道题或追问上一条回答。点击「发送」，或按 Ctrl / ⌘ + Enter 发送。

  2. 等待回复完成

    请求过程中会显示等待状态。回复成功后可继续追问；回答旁的复制按钮可复制文本。

  3. 按需开启新话题

    点击「清空对话」重置聊天上下文。此操作会清除当前页面的聊天记录，API 配置仍保留。

可复制的学习提问示例
请用中文解释「机会成本」，先给出简明定义，
再用一个大学生日常选择的例子说明，最后列出容易混淆的点。

连续追问

每次请求会携带最近 10 轮对话。你可以直接追问「再举一个例子」或「把第二点讲得更详细」。

刷新后的变化

聊天记录保留在当前页面内，刷新后清空。API 地址、Key、模型和超时设置保存在油猴的本机存储中。

测试连接成功代表接口能回复文本；具体问题的答案仍需要结合课程内容核对。

06 / QUESTION SEARCH

在线搜题与划词

在线搜题会直接调用你配置的 AI。当前版本已经移除题库与答案缓存，重复搜索同一道题也会重新发起请求。

  1. 切换到「在线搜题」

    在「搜索题目」输入框里粘贴题目。选择题应包含题干、题型与全部选项；填空题应说明空格顺序。

  2. 点击「搜索」

    等待结果，面板会显示耗时、答案或接口错误。无需选择题库、题库来源或来源模式。

  3. 查看并核对答案

    需要详细推导时，将题目放到「AI 聊天」中，明确要求解释过程。在线搜题主要用于取得可解析的答案。

完整题目示例
【单选题】下列哪一项属于可再生能源？
A. 煤炭
B. 太阳能
C. 石油
D. 天然气
划词搜索是怎么工作的？

「划词搜索」默认开启。在页面中选中文字后，脚本会把选中的文本带入「搜索题目」输入框；你可以切到在线搜题，补全选项，再点击「搜索」。

选中文字本身不会立即调用接口。只想手动粘贴题目时，可以关闭「划词搜索」。

题目中有图片、公式或表格当前 AI 接入发送的是文本消息，没有专门的图片识别流程。请把必要的图片信息、公式和表格内容整理成文字后再提问；缺失关键信息时，模型可能不给出有效答案。

平台功能与自动作答

代码内保留了多个网课平台的适配入口。菜单会按当前页面及已登记的 iframe 地址匹配，实际可用性还取决于平台页面结构和原配套服务。

智慧职教学习中心、MOOC 学院课程学习、作业考试。不同站点和页面的入口有所区别。

这张表说明源码里包含哪些适配，并不代表所有课程、所有新版页面都已逐一验证。浏览器地址匹配成功后，通常仍需要进入视频或题目详情页。

开始一轮任务

  1. 先让「测试连接」成功

    进入「设置」，确认「答题后操作」符合你的需要。默认是「由我手动保存或提交」。

  2. 手动进入课程的题目页面

    等待脚本识别页面，查看主导航下方出现的平台入口。部分流程会显示 5 秒后自动答题的提示，可在倒计时内取消。

  3. 按当前页面的提示操作

    若面板显示「开始答题」，可点击启动。运行中可使用暂停、继续或重新答题等控制；各平台具体控件以实际面板为准。

  4. 到「答题结果」检查进度与错误

    点击题目序号查看结果。AI 未配置、调用失败、没有有效答案或无法匹配选项时，题目会保留供手动处理；脚本已移除随机作答兜底。

  5. 核对后手动保存或提交

    默认设置不会替你直接提交。先检查题目填写情况，再使用课程页面自身的保存、提交按钮。

视频弹题

部分平台的视频题目可选择 AI 答题或忽略。AI 给出有效答案且匹配成功时，脚本会选择相应选项；失败时需要手动完成弹题。若页面提示完成后刷新，请按提示恢复流程。

看到本地服务连接错误时

服务职责配置来源
你填写的 AI API回答聊天和题目，提供模型文本回复。「AI 聊天」中的 API 地址、Key 和模型。

按功能分别判断如果你已有原配套环境，确认本地服务正在运行。未配置该环境时，可以先用 AI 聊天和手动在线搜题，这两项直接使用你的 AI 接口。修改 API 地址无法代替启动平台操作配套服务。

08 / SETTINGS

设置怎么选

「设置」页把常用选项放在前面，其他选项收在「高级设置」。刚开始使用时可以先保留默认值，遇到具体问题再调整。

三个常用设置

设置默认值 / 范围作用
搜题间隔（秒）默认 3；0～60。控制自动作答中的搜题节奏。遇到限流时可增加间隔。
答题后操作由我手动保存或提交。可选只保存、全部完成时提交或直接提交。初次使用保留手动方式，便于核对。
保存或提交前等待（秒）默认 3；0～60。在适配支持的自动保存 / 提交流程中，设置动作前的等待时间。

高级设置

选项默认状态什么时候调整
系统通知只显示右下角通知。按需启用提示音、任务栏提示或关闭通知。
搜题并发数1；范围 1～5。增大后可能更快，也更容易触发服务商限流。出现 429 时可调低。
答案分隔符===,#,---,###,|,;,；用于答案拆分与匹配。通常保留默认值。
题干需移除的文字空。若平台题干包含固定的无关文字，可每行填一项进行清理。
对非任务点题目答题关闭。只在你明确需要处理相应页面题目时开启，实际效果受平台适配影响。
答案匹配模式相似匹配。精确匹配要求选项文字完全一致；答案与选项对不上时，可结合题目文本检查。

高级项被修改后，折叠标题会标记「已修改」，收起也能看见状态。各平台学习页还可能有音量、倍速、复习或定时停止等独立选项。

10 / UPDATES & DATA

更新与配置保存

  1. 从油猴检查更新，或打开「高级工具 → 版本更新」

    当前脚本的更新地址指向本仓库的最新 GitHub Release。确认新版本后安装或更新，再刷新网课页面。

  2. 更新前按需备份

    可以使用 Tampermonkey 管理面板的导出功能备份脚本和设置；具体选项随扩展版本而异，见 官方导入导出说明。备份可能包含自己的密钥，请自行妥善保存。

  3. 换浏览器或设备后检查接口配置

    脚本设置保存在油猴的本机存储里。换到新的浏览器配置文件或设备后，重新填写或自行迁移配置，并再次测试连接。

AI 请求发往你填写的接口。脚本会按用途发送聊天消息，或题干、题型与选项文本；使用前可自行确认接口服务商的数据处理规则。

11 / TROUBLESHOOTING

按你看到的错误排查

先看脚本面板中的具体错误，再按下面的情况检查。搜索只筛选本节内容，不会向外发送查询。

安装后没有按钮，面板也不显示
  1. 在油猴管理面板确认「小肥鱼AI」已经安装并启用。
  2. 确认 Tampermonkey 的用户脚本执行权限，以及对当前网站的访问权限。
  3. 打开脚本匹配的网课页面，并刷新。
  4. 尝试点击右下角星形按钮，或使用 Ctrl + O。
  5. 确认没有同时启用会干扰页面的旧版脚本。

如果网课主页只有通用入口，继续进入具体课程或题目页面。

提示「请配置 API 地址和模型名称」

打开「AI 聊天」，填写有效地址和模型 ID。每项填完点击框外的位置保存，确认超时在 5～300 秒。无需鉴权的本地服务可以不填 Key，但仍需填写地址与模型。

HTTP 401 / 403：鉴权或访问失败

检查 Key 是否完整、是否来自当前 API 地址对应的服务商、是否有权限调用该模型。输入框填写密钥本身，脚本会自动添加 Bearer 前缀。403 还可能是服务商的模型权限或访问限制，请结合错误正文确认。

HTTP 404，或提示找不到模型 model not found

先核对接口路径，查看本教程的地址拼接预览。再检查模型 ID 是否由这个接口提供；服务商的网页展示名称和实际 API 模型 ID 可能不同。必要时填入服务商给出的完整 Chat Completions URL。

HTTP 429：限流或额度问题

阅读服务商返回的错误正文，检查调用频率和账户可用额度。暂停连续重试；自动作答时可将并发数降到 1，并增加搜题间隔。手动重复搜索也会产生新的 API 请求。

HTTP 5xx：服务端暂时无法处理

保留错误码和时间，稍后重试，或查看服务商状态说明。先用「测试连接」确认基础调用是否恢复，再继续平台任务。

返回非 JSON，或出现 HTML 页面内容

通常需要检查 API 地址。确认填写的是接口服务地址，特别是 /chat/completions 路径；返回登录页面、网站首页或网关错误页时，脚本无法读取模型回复。

AI 网络请求失败 / 跨域访问权限

检查网络、域名、HTTP(S) 地址和油猴对接口域名的访问授权。若油猴弹出该接口的访问请求，确认目标确实是你配置的服务后按需允许。模型服务运行在本机时，确认端口可访问且服务已启动。

AI 请求超时，或者回复特别慢

默认等待 60 秒。可以在「AI 聊天」把超时调整到 90、120 秒等合适值，最高 300 秒；然后用简单问题测试。若长时间无法完成，再检查服务状态、模型响应速度或网络。

聊天能回答，搜题却提示答案 JSON 格式错误

聊天接受普通文本，而搜题要求模型按脚本提示返回 {"answers":["答案"]}。补全题干和选项后重试，确认模型能遵循结构化输出要求；也可以把题目放到 AI 聊天中人工查看答案。聊天系统提示词只影响聊天。

显示空内容，或模型接口不兼容

确认服务支持 Chat Completions 文本回复，并能在回复内容中提供文本。有些模型或接口只返回其他类型结果，当前接入无法据此填写答案。先用「测试连接」验证，再按服务商说明选择支持的接口和模型。

AI 有答案，选项却没有自动填上

查看「答题结果」里的错误，确认完整选项能与 AI 答案匹配，检查题目是否属于已适配页面。无法匹配、模型返回不确定答案或平台 DOM 发生变化时，都需要手动处理。当前版本不会使用题库或随机选项兜底。

localhost:15319 / 本地服务连接失败

这是部分平台操作依赖的原配套环境。若你已有该环境，确认软件及其本地服务正在运行；本仓库提供的是用户脚本，没有附带该服务。AI 聊天和手动在线搜题可直接通过配置的 AI 接口使用。

页面没有平台按钮，或者课程流程不启动

确认已进入视频或题目详情页，等待子页面加载后刷新；也可查看「高级工具」里的平台提示。平台菜单按 URL 匹配显示，已有入口也不代表平台的所有新版页面都已验证。需要原配套服务的功能，还需检查对应环境。

划词后没有直接搜索 / 搜索题目不完整

先确认「在线搜题」里的划词搜索开关已开启。选中文字会填入题目框，随后需要点击「搜索」；检查是否选全题干和选项，缺失部分可手动补充。

刷新后聊天记录没了 / 换浏览器后 Key 没了

聊天只保留在当前页面，刷新后清空；Key 和其他配置保存在原浏览器的油猴存储中。换设备或浏览器配置文件后，需要重新填写或自行迁移配置。原配置同步功能不包含 AI 设置字段。

没有匹配的问题。试试更短的关键词，或清除搜索查看全部。

反馈问题时，带上这些信息脚本版本、浏览器版本、平台名称、页面类型、完整错误文字，以及遮住 Key 和个人信息后的截图。可以通过 GitHub Issues 反馈。
12 / FOR DEVELOPERS

修改源码与打包

这一节用于自己修改脚本。日常使用时，安装 Release 中已经合并好的 .user.js 即可。

展开开发环境、构建与发布步骤

准备环境

使用 Node.js 22.13 或以上版本（项目推荐 24），以及项目锁定的 pnpm 10.26.1。在项目根目录执行：

安装依赖与验证
pnpm install --frozen-lockfile
pnpm run build
pnpm run check
pnpm test
pnpm run package

修改流程

编辑 src/ 下对应模块，运行 pnpm run build 更新根目录的 xxx.js 与 xxx.user.js，再运行检查和测试。生成文件会在下次构建时重写。

要修改的内容源码位置
脚本名、作者、版本、匹配网站src/meta/userscript-header.txt
API 地址处理与请求、答案解析src/kernel/12-ai-client.js
主菜单和面板导航src/kernel/20-ui-render.js
AI 聊天与设置面板src/kernel/32-project-common.js
样式与悬浮入口src/ui/theme.css、src/entries/ai-entry.js
模块拼接顺序tools/module-map.mjs

得到单文件安装包

pnpm run package 会直接从源码生成 dist/ai-course-assistant.user.js、更新用的 .meta.js 和 SHA256SUMS。油猴只需安装完整的 .user.js。

GitHub 自动发布

更新元数据中的版本号、构建并提交相关文件，再推送匹配的版本标签。例如 @version 2.44.4 对应 v2.44.4。GitHub Actions 检查通过后会创建 Release 并上传发布文件；普通 main 推送也会运行构建检查。

所有模块共享原有闭包，通过映射表按顺序拼接。新增模块应登记到映射表，维护方式详见仓库 README。
